# Equation and Diagnostic Implementation Map

References below use the finalized revised manuscript PDFs supplied locally as `eta-main-revised.pdf` and `eta-supp-info-revised.pdf`. TeX labels are included in parentheses so the mapping remains stable if journal production renumbers equations.

| Manuscript object | Equation / Algorithm reference | Code location | Implementation notes |
|---|---|---|---|
| Extreme set and scalar observable | Main Eq. (1), `eq:extreme-set`; main Problem Statement, `sec:ps` | `notebooks/toy--2D->1D.ipynb`, `notebooks/toy--2D->2D.ipynb`, `notebooks/ERA5Land.ipynb`, `notebooks/ERA5Land-EVD.ipynb`, `notebooks/ERA5Land-DGM-Plot.ipynb`; CLI mirrors in `experiments/toy_2d_to_1d.py`, `experiments/toy_2d_to_2d.py`, `experiments/era5land.py`, `experiments/era5land_evd.py`, `experiments/era5land_dgm_plot.py` | The manuscript pipeline is `x -> u(x) -> g(u(x))`. Toy scalar learning directly uses `y(x)`. Toy state learning uses `g(u)=2|u_1|+|u_2|/2`. ERA5-Land uses `g(u)=max(u)` over HR grid cells. |
| Supervised empirical loss / ERM | Main Eqs. (2)-(4), `eq:erm`, `eq:uerm`, `eq:l2-loss` | `src/train_utils.py::train_nn`, `src/train_utils.py::train_eta_xy`, `src/train_utils.py::train_eta_xuy`, `src/revision_utils.py::train_srcnn_mse_no_save`, precipitation notebook `train_model_eta` cells, `experiments/common.py::train_srcnn_mse_cli`, toy CLI scripts | Uses `torch.nn.MSELoss` on paired samples `(x_i, y_i)` for scalar learning or `(x_i, u_i)` for state learning. |
| 1-Wasserstein distance | Main Eq. (5), `eq:W1` | `src/metric.py::wloss`, `src/revision_utils.py::tail_w1_quantile` | The implementation only needs the one-dimensional observable law, so training uses the quantile form below rather than a high-dimensional transport solve. |
| Pushforward observable samples `(g o phi)_# mu` | Main Eqs. (11)-(12), `eq:geneces`, `eq:geneces-u`; main Methods Eq. (14), `eq:prac-geneces-u` | `src/train_utils.py::train_eta_xuy`, precipitation notebook `train_model_eta` cells, `src/revision_utils.py::train_precip_eta_no_save`, `experiments/common.py::train_precip_eta_cli`, `experiments/common.py::evaluate_precip_model` | Model outputs are evaluated on a large inference/LR set, then reduced to scalar observable samples before sorting or quantile selection. |
| One-dimensional Wasserstein-1 / quantile formula | Main Methods Eq. (13), `eq:w1-quantile`; SI Theorem S18 and SI Eq. (13) | `src/train_utils.py::train_eta_xy`, `src/train_utils.py::train_eta_xuy`, `src/revision_utils.py::empirical_quantiles`, `notebooks/ERA5Land-EVD.ipynb` GEVD quantile cells, `experiments/common.py::gevd_reference`, `experiments/common.py::empirical_quantiles` | Reference law `nu_0` is represented by empirical, analytic, fitted, or GEVD-derived quantiles on a selected grid `Q`; model quantiles are estimated as empirical order statistics. |

| Eta-learning state objective | Main Eq. (12), `eq:geneces-u`; practical main Methods Eq. (14), `eq:prac-geneces-u` | `src/train_utils.py::train_eta_xuy`, `notebooks/ERA5Land.ipynb`, `notebooks/ERA5Land-EVD.ipynb`, `src/revision_utils.py::train_precip_eta_no_save`, `experiments/toy_2d_to_2d.py`, `experiments/era5land.py`, `experiments/era5land_evd.py`, `experiments/common.py::train_precip_eta_cli` | Optimizes supervised state MSE plus `lambda * W1((g o phi)_# mu, nu_0)`, applying the distributional term only to the scalar observable. |
| Continuation from MSE baseline | Main Methods, "Effective Training Strategies"; SI Algorithm 1, `alg:train` | `notebooks/toy--2D->1D.ipynb`, `notebooks/toy--2D->2D.ipynb`, `notebooks/ERA5Land.ipynb`, `notebooks/ERA5Land-EVD.ipynb`, `experiments/toy_2d_to_1d.py`, `experiments/toy_2d_to_2d.py`, `experiments/era5land.py`, `experiments/era5land_evd.py` | The eta model is initialized from the architecture-matched ERM/MSE baseline and then continued with the combined supervised plus W1 objective. |
| IICT / quantile-index refresh | SI Algorithms 1-2, `alg:train`, `alg:update` | `src/train_utils.py::train_eta_xy`, `src/train_utils.py::train_eta_xuy`, `src/revision_utils.py::get_max_time_pos`, `src/revision_utils.py::get_fixed_days_max_pos`, precipitation notebook `train_model_eta` cells, `experiments/common.py::train_precip_eta_cli` | Maintains inference indices `I` realizing target quantiles and, for max observables, output component indices `J`; refreshes every `omega` iterations or epochs. |
| Tail-biased quantile grid `Q` | Main Methods Eq.
